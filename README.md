# CRC-MMR-study

Analysis code and supporting materials for a study of gut microbiome differences
between mismatch repair-deficient (dMMR) and mismatch repair-proficient (pMMR)
colorectal cancer, and their associations with immunotherapy response.

## Repository organization

Planned directory structure:

```text
CRC-MMR-study/
├── README.md
├── LICENSE
├── .gitignore
├── script/
├── data/
│   ├── inputdata/
│   └── intermediate/
└── results/
    ├── figures/
    ├── tables/
    └── supplementary/
        ├── figures/
        └── tables/
```
